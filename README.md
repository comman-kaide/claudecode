# 日報アプリ | Daily Report App

小規模チーム（社員数10名以下）向けのシンプルな日報管理アプリケーションです。

## 機能

- **メンバー管理**: チームメンバーの追加・削除（最大10名）
- **日報作成**: 今日やったこと、明日やること、困っていること、メモを記録
- **日報一覧**: 全員の日報を閲覧、ユーザー・日付でフィルタリング
- **日報編集・削除**: 提出済みの日報を編集・削除
- **提出状況確認**: 日付ごとの提出済み/未提出メンバーを一覧表示
- **レスポンシブ対応**: スマートフォン・タブレットでも利用可能

## セットアップ

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. サーバーの起動

```bash
npm start
```

開発モード（ファイル変更時に自動再起動）:
```bash
npm run dev
```

### 3. アプリケーションへのアクセス

ブラウザで以下のURLを開きます:
```
http://localhost:3000
```

## 使い方

### 1. メンバーを登録する

1. 「メンバー管理」タブを開く
2. 名前とメールアドレスを入力
3. 「メンバーを追加」をクリック

### 2. 日報を書く

1. 「日報を書く」タブを開く
2. 名前を選択し、日付を確認
3. 各項目を入力:
   - **今日やったこと** (必須): 本日の作業内容
   - **明日やること**: 翌日の予定
   - **困っていること・相談事項**: 課題や相談したいこと
   - **メモ・その他**: その他の連絡事項
4. 「日報を提出」をクリック

### 3. 日報を確認する

1. 「日報一覧」タブを開く
2. 必要に応じてフィルタで絞り込み
3. 日報の編集・削除が可能

### 4. 提出状況を確認する

1. 「提出状況」タブを開く
2. 日付を選択
3. 提出済み・未提出のメンバーを確認

## APIエンドポイント

### ユーザー管理

| メソッド | エンドポイント | 説明 |
|---------|---------------|------|
| GET | `/api/users` | 全ユーザー取得 |
| POST | `/api/users` | ユーザー追加 |
| DELETE | `/api/users/:id` | ユーザー削除 |

### 日報管理

| メソッド | エンドポイント | 説明 |
|---------|---------------|------|
| GET | `/api/reports` | 日報一覧取得 |
| GET | `/api/reports/:id` | 日報詳細取得 |
| POST | `/api/reports` | 日報作成 |
| PUT | `/api/reports/:id` | 日報更新 |
| DELETE | `/api/reports/:id` | 日報削除 |

### 統計

| メソッド | エンドポイント | 説明 |
|---------|---------------|------|
| GET | `/api/stats?date=YYYY-MM-DD` | 提出状況取得 |

### ヘルスチェック

| メソッド | エンドポイント | 説明 |
|---------|---------------|------|
| GET | `/api/health` | サーバー状態確認 |

## プロジェクト構成

```
.
├── server.js              # Expressサーバー
├── package.json           # プロジェクト設定
├── .gitignore            # Git除外設定
├── public/
│   └── index.html        # フロントエンドUI
└── data/                 # データ保存（自動生成）
    ├── users.json        # ユーザーデータ
    └── reports.json      # 日報データ
```

## 技術スタック

### バックエンド
- **Node.js**: サーバー環境
- **Express**: Webフレームワーク
- **uuid**: ユニークID生成

### フロントエンド
- **HTML5**: マークアップ
- **CSS3**: スタイリング（レスポンシブ対応）
- **Vanilla JavaScript**: UI制御、Ajax通信

### データ保存
- **JSONファイル**: シンプルなファイルベースストレージ

## 制限事項

- チームメンバーは最大10名まで
- 同じユーザーは同じ日に1つの日報のみ提出可能
- データはJSONファイルに保存（大規模なデータには不向き）
