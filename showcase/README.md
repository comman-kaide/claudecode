# 計算でできた光

生成AIの実力を、説明ではなく **証拠** で見せるための作品。

`index.html` 一枚だけで完結します。画像・動画・フォント・ライブラリ・外部通信は
すべてゼロ。目に見えるものは全部、閲覧者の端末がその場で計算した結果です。

## 中身

| | 図版 | 手法 | 触れる |
|---|---|---|---|
| 序 | 流れ | カールノイズの流れ場を数万個の粒子が流れる | カーソルで粒子を押しのける |
| 一 | 生命 | Gray–Scott 反応拡散系（チューリング・パターン） | なぞると模様が育つ |
| 二 | 混沌 | ドジョン・ストレンジアトラクタの密度蓄積 | — |
| 三 | 共鳴 | クラドニ図形を砂粒単位で解く | 2つの周波数つまみ |
| 四 | 成長 | 再帰的な枝分かれ＋風の揺らぎ | クリックで別の木が育つ |
| 五 | 立体 | 距離関数によるメンガーのスポンジのレイマーチング（WebGL） | ドラッグで回る |
| 解剖 | 計測値 | 更新回数・fps・端末情報の実測ダッシュボード | — |
| 終 | 署名 | 粒子が文字の形に集まる | — |

## 設計メモ

- **単一テキストファイル。** HTML・CSS・JavaScript・GLSL がこの1ファイルに入っています。
  ページ内の統計（画像0枚 / 外部ファイル0件 / ソースの大きさ / 行数）は、
  ハードコードではなく閲覧時に DOM を数えて出しています。
- **計測は実測。** 「1秒あたりの更新回数」は各エンジンが実際に回した粒子数・格子数を
  数えたもの。誇張しないよう、単位（粒子・格子・点・砂粒・枝・光線）を明記しています。
- **見えていない図版は動かしません。** IntersectionObserver で画面外のエンジンを止め、
  端末の負荷を抑えています。
- **端末に合わせて重さを変えます。** 格子数・粒子数・バッファ解像度は画面の面積から
  算出し、縦長の画面でも計算量が跳ねないよう上限を設けています。
- **`prefers-reduced-motion` を尊重します。** 指定があるときは各図版を数百フレームだけ
  進めて静止画として止めます（絵は完成した状態で残ります）。
- **単一テーマ（暗）です。** 観測記録という主題に合わせた意図的な選択で、
  ライトテーマへの切り替えでも配色を保ちます。

## 見る

そのままブラウザで `index.html` を開くだけです。ビルドもサーバーも要りません。
